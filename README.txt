OneVoice27 SOP and Daily Bible Chapter Reminder (1 Oct - 31 Dec 2026)

GET THE APK WITHOUT INSTALLING ANYTHING (GitHub, free):
 1. Create a new repository on github.com and upload everything in this folder
    (keep the hidden .github folder).
 2. Open the repository's "Actions" tab. The "Build APK" job runs automatically
    (or press "Run workflow").
 3. After about 5 minutes, open the finished run and download "OneVoice27-apk".
    Unzip it to get OneVoice27-SOP-Bible-Reminder-release.apk and share it with members (WhatsApp, etc.).

OR WITH ANDROID STUDIO:
 Open this folder, wait for Gradle sync, then Build > Build App Bundle(s)/APK(s) > Build APK(s).

INSTALLING ON A PHONE
 - Allow "Install unknown apps" for WhatsApp/Files when asked.
 - Open the app once and allow notifications. Reminders are then set automatically
   (Bible 06:00 daily, Desire of Ages Sunday 06:30) or members can set their own under "Reminders".
 - On some Tecno/Infinix/Itel/Xiaomi phones, set battery usage for the app to
   "No restrictions" so reminders aren't blocked.

Reading data is in app/src/main/assets/index.html (Bible: Psalm 55-146; Desire of Ages: Ch. 1-23).
